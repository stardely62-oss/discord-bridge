# Стратегии

## Формат Bridge (схема v1)

```json
{
  "schemaVersion": 1,
  "id": "my-general",
  "name": "Моя стратегия",
  "description": "Копия general с другим fake",
  "source": "custom",
  "engine": "winws",
  "origin": { "baseId": "flowseal-general", "flowsealVersion": "1.10.4" },
  "requirements": { "tcpTimestamps": true, "gameFilter": true, "userLists": true },
  "global": [
    { "opt": "--wf-tcp", "value": "80,443,2053,2083,2087,2096,8443,%GameFilterTCP%" },
    { "opt": "--wf-udp", "value": "443,19294-19344,50000-50100,%GameFilterUDP%" }
  ],
  "rules": [
    {
      "label": "Голос Discord",
      "enabled": true,
      "args": [
        { "opt": "--filter-udp", "value": "19294-19344,50000-50100" },
        { "opt": "--filter-l7", "value": "discord,stun" },
        { "opt": "--dpi-desync", "value": "fake" },
        { "opt": "--dpi-desync-fake-discord", "value": { "fake": "ACTIVE_DISCORD_UDP.bin" } },
        { "opt": "--dpi-desync-repeats", "value": "6" }
      ]
    }
  ]
}
```

- `global` — параметры движка (перехват WinDivert), выводятся первыми.
- `rules` — профили winws в исходном порядке, разделяются `--new`. Порядок важен:
  пакет обрабатывает первое подходящее правило. Выключенные правила пропускаются.
- Значение параметра — строка, `{"fake": "<файл из bin>"}` или `{"list": "<файл из lists>"}`.
  Пути не допускаются: служба сама подставляет защищённые каталоги.
- `%GameFilterTCP%` / `%GameFilterUDP%` в портах заменяются по настройке «Игровой фильтр»
  (выключен → `12`, как в Flowseal).
- Списки `list-general-user.txt`, `list-exclude-user.txt`, `ipset-exclude-user.txt`
  формируются из ручных списков, `ipset-all.txt` — по режиму «Какие IP идут через обход»
  (см. ARCHITECTURE.md, «IP-наборы»).
- Неизвестные поля и параметры отклоняются. Полный список параметров и типов значений —
  `crates/bridge-core/src/strategy/options.rs` (он же питает визуальный редактор).

### Миграции

Документы читаются как JSON, поэтапно обновляются до текущей версии
(`strategy/migrate.rs`), затем строго десериализуются. Перед перезаписью
мигрированного файла создаётся копия `*.v<старая версия>.bak`. Документы более
новой версии отклоняются.

## Импорт BAT

Поддерживаемое подмножество: `@echo off`, `echo`, `chcp N > nul`, `::`/`rem`,
`setlocal`, `title`, `pause`, `exit`, `cd /d "%~dp0"`/`%BIN%`,
`set "BIN=%~dp0bin\"`, `set "LISTS=%~dp0lists\"`, литеральные `set`,
`call service.bat status_zapret|check_updates|load_game_filter|load_user_lists`
(фиксируются как требования, не выполняются) и **один** запуск
`start "…" /min "%BIN%winws.exe" …` (или прямой вызов), в том числе с переносами `^`.

Правила разбора: кавычки и экранирование `^` как в cmd; `& | < >` вне кавычек — ошибка;
неизвестные `%ПЕРЕМЕННЫЕ%` — ошибка; значения `%BIN%имя` → fake-ресурс,
`%LISTS%имя` → список; любой другой путь — ошибка. Строки вне подмножества
перечисляются с номерами; сохранить стратегию можно только подтвердив импорт
поддерживаемых частей.

## Сравнение

Структурный diff: изменения названия/описания/требований, построчный diff
глобальных параметров, правила сопоставляются по (протокол, порты, списки) через LCS,
для каждой пары — изменения портов, L7, списков, доменов, fake-файлов, desync и
прочих параметров плюс построчный diff аргументов. Отдельно сообщается об изменении
порядка правил.

## Черновики

Стратегию с ошибками валидации можно сохранить как черновик (значок «черновик»
в списке), но нельзя запустить. Небезопасные данные (пути в именах ресурсов,
управляющие символы, превышение лимитов) не сохраняются вовсе.

## Импорт: подтверждение

Предпросмотр сохраняет исходный файл в памяти под токеном. При импорте файл
разбирается **заново** на стороне Rust; из интерфейса принимается только новое
название. Частичный импорт (с неподдерживаемыми строками) требует явного согласия.

## Discord Only

«Стратегии → ⋯ → Discord Only» создаёт пользовательскую копию `general`, где
убраны правила для Google, `ipset-all` и игрового фильтра, а `list-general.txt`
заменён доменами Discord. Правило голоса (UDP 19294-19344, 50000-50100,
discord/stun) сохранено. Ограничение — по доменам и портам, не по процессу.
